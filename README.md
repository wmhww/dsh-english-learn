# dsh-english-learn 英语学习

一个 DeepSeek Harness (dsh) 插件：**四六级词库，一次学一组 20 个词**，带音标、中文释义、短语搭配、例句、拼写练习和间隔重复复习。全部离线运行，进度存在 GUI 本地。

词库是**开源的四六级大纲单词表**，不是手写的——见 [NOTICE.md](NOTICE.md)。

## 学习方式：一次 20 个词

**没有分类可选。** 词库是一条按词频排好的序列，点「开始学习」就取接下来的 20 个词，学完直接给下一组：

```
开始学习 · 20 词  →  学完这 20 个  →  学习下一组 · 20 词  →  ...
```

- 每组固定 20 个词（可在设置里改成 5–50）
- 顶部显示整库进度：`已学 40 / 5371`、`还剩 5331 个新词`
- 整库学完后，「学习」自动转为复习到期的词，不会变成死胡同
- 「进度」页按级别展示进度，那只是**你走到哪儿了**的说明，不是要你选的东西

## 功能

| 页面 | 说明 |
| --- | --- |
| **学习** | 一次一组 20 词。每张卡片显示单词、**音标**、词性、中文释义；有短语搭配和例句的卡片会一并显示（点击句子可朗读）。四档评分（忘记了 / 有点难 / 记住了 / 太简单），每档实时显示下次复习间隔。 |
| **拼写** | 根据中文释义和音标拼写单词，从**已学过的词**里出题。提示按钮逐字揭示，提交后逐字母标红/标绿，回车键连续作答。 |
| **测验** | 选择题，三种题型混排：英译中、中译英、例句填空。从已学的词里出题，答错的词会汇总回顾。 |
| **复习** | 只抽取**到期**的单词（SM-2 精简算法）。显示今日待复习数、已学数、已掌握数、连续学习天数。 |
| **进度** | 词库总量、已学、待复习、已掌握、正确率、连续天数；各级别进度条；最近学习记录；偏好设置（每组词数、自动朗读、口音、先隐藏释义）。 |

## 词库：四六级大纲单词表

**5,371 词**，来自公开发布的《大学英语四级/六级大纲单词表》：

| 级别 | 词数 | 组数（每组 20） |
| --- | --- | --- |
| 四级核心 | 4,195 | 210 |
| 六级进阶 | 1,176 | 59 |

> 六级只有 1,176 词，是因为**四级已收的词不重复计入六级**——六级表里与四级重叠的部分留在四级，六级只放它独有的部分。两表合并去重后共 5,371 词。

词表内部按 BNC/COCA 词频排序，所以每一组都是从更常用的词走到更少用的词。

### 每张卡片包含什么

| 字段 | 覆盖率 | 说明 |
| --- | --- | --- |
| **音标** | 99.9% | ipa-dict 英式音标为主，缺失时用大纲表自带的音标，再兜底 ECDICT |
| **中文释义** | 99.4% | 大纲表的考试义项优先（`in` 不会被解释成"执政者"） |
| **例句** | 73% | Tatoeba 真人翻译；3,079 词有 2 条 |
| **短语搭配** | 20% | ECDICT 搭配，且必须在真实语料中出现过 |

**短语和例句是「有就用，没有也收」**——这是刻意的取舍。完整的考纲词表比每张卡片都配齐例句更重要；1,345 个词只有音标和释义，UI 会自动隐藏空的小节。早期版本要求每词必须有 2 条搭配 + 例句，结果词库只剩 90 词。

### 已剔除的内容

- **74 个虚词**（`be` `of` `and` `in` `to`…）：考纲要枚举它们，但它们不是生词
- **227 个词频过高**（BNC < 300）的词：同上，CET 考生早就会了
- **不合适的句子**：脏话、性内容、月经/堕胎等话题整句丢弃。`drunk` 这类正常词保留，只丢不合适的例句

## 生成规则

**必须有**（缺了就不收这个词）：

1. **音标**——ipa-dict → 大纲表 → ECDICT，三级兜底
2. **中文释义**——大纲表的考试义项优先，缺失时用 ECDICT 的短义项
3. **实词**——介词、连词、代词、助动词等虚词不作词条
4. **不是高频词**——BNC/COCA 词频低于 300 的不收

**有则更好**（不影响收录）：

- **短语搭配**——以词条为锚点（`make a decision` ✓，`a man of decision` ✗），必须在真实语料中出现过（挡掉 `hard rush`＝灯心草这类词典词条），且与所教义项一致
- **例句**——Tatoeba 真人翻译，4–16 词，无专有名词，无脏话，义项一致的优先

还有两道去重，防止卡片浪费位置：同一句话的缩写/非缩写形式（`We are` / `We're`）只留一条；只差一个冠词的搭配（`our species` / `the species`）只留一条。

## 安装位置

插件在界面里有两个入口，内容相同：

1. **侧边栏底部**「📘 英语学习」按钮 —— 打开全屏面板。
2. **设置 → 英语学习** —— 作为一级设置页内嵌显示。

## 数据与隐私

学习进度、收藏和偏好全部保存在浏览器 `localStorage` 的 `dsh-english-learn/v1` 键下。不联网、不上传、不写宿主存储。发音使用浏览器内置的 Web Speech API。

## 开发

```bash
node scripts/import-data.mjs                            # 校验/解压数据
node --max-old-space-size=6144 scripts/pipeline.mjs     # 重新生成词库
node scripts/audit.mjs                                  # 内容审计
node scripts/build.mjs                                  # 构建 lib/
node scripts/verify.mjs                                 # 跑全部验证
```

`pipeline.mjs` 需要较大堆内存（ECDICT 有 77 万行）。

构建是**拼接**而不是打包：`core.mjs` 去掉 `export` 后与 `ui.js` 一起内联进一个模块工厂作用域，词库 JSON 作为字面量注入。因此插件没有任何运行时依赖。

`verify.mjs` 会真正执行 `lib/client.js`：它把 bundle 喂给一个 DOM / React 垫片，用假的 Cordis 上下文调用 `apply()`，然后逐个点击开始按钮、评分按钮、拼写输入框和测验选项，断言进度确实写进了存储。

## 调度算法

精简版 SM-2，四档评分：

- `忘记了` —— 间隔归零、立即重来，难度系数 −0.2（下限 1.3），记录一次遗忘。
- `有点难` —— 间隔 ×1.2，难度系数 −0.15。
- `记住了` —— 间隔 ×难度系数（新卡从 1 天起）。
- `太简单` —— 间隔 ×难度系数 ×1.3，难度系数 +0.15（上限 3.2）。

间隔上限 365 天。
